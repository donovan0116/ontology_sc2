# Ontology SC2 Agent V0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development
> (recommended) or superpowers:executing-plans to implement this plan task-by-task.
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a runnable, testable minimal Terran bot and durable experiment pipeline.

**Architecture:** Pure domain/config/policy modules are isolated from BurnySc2. A thin bot
adapter produces snapshots and delegates macro intents to an executor; runner boundaries own
artifacts, replay configuration, failures, and batch aggregation.

**Tech Stack:** Python 3.11, BurnySc2 7.3.0, PyYAML, pytest, Ruff, mypy.

## Global Constraints

- V0.1 only; no V0.2 managers and no RDF/OWL/graph dependencies.
- All thresholds are typed YAML configuration.
- Real SC2 integration is opt-in and may never be reported as passed unless it ran.
- Every per-game run writes an effective config, events, metrics, and error on failure.
